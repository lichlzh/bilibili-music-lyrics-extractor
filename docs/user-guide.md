## 1. 安装

### 1.1 Windows（推荐：GitHub Actions 自动构建）
仓库已配置 GitHub Actions（`.github/workflows/build-windows.yml`）。每次推送到 `main`/`master` 会自动在 Windows 环境构建安装包：
1. 打开仓库页面 → **Actions** 标签页 → 找到 `Build Windows App` 运行记录；
2. 等状态变绿（首次约几分钟，需要下载 Electron 运行时）；
3. 在页面底部 **Artifacts** 处下载 `B站音乐下载器-Windows` 压缩包；
4. 解压后运行 `Setup.exe` 安装即可。

> 安装包**未做代码签名**，Windows SmartScreen 可能弹出拦截提示，选择「仍要运行 / 更多信息 → 仍要运行」即可，属正常现象。

### 1.2 macOS
```bash
npm install
npm run dist      # 生成 dist/B站音乐下载器-*.dmg
```
未做公证（`identity: null`），首次打开未签名 dmg 时，可能需在「系统设置 → 隐私与安全性」中手动允许。

### 1.3 从源码以开发模式运行
```bash
npm install
npm run dev       # 自动打开应用窗口
```

## 2. 快速开始

1. **选择输出目录**：在顶部设置里指定歌曲与歌词的保存位置（建议本地磁盘，避免网络盘）。
2. **添加歌曲**：粘贴 B 站链接或 BV 号，填写「歌名」与「类型」（原唱 / 伴奏），点击加入歌单。
3. **开始下载**：点击「开始全部」，应用会逐条用 `yt-dlp` 抓取、`ffmpeg` 转码为 MP3，并展示进度。
4. **查看状态**：每首歌显示 等待中 / 下载中 / 转码中 / 已完成 / 失败 / 已取消。

---

## 3. 歌词下载与状态说明（重点）

每首歌转码完成后，应用会**自动下载一份同名的 `.lrc` 歌词文件**（原唱、伴奏各自一份，文件名与 MP3 完全一致，便于音箱按名匹配）。

歌曲条目右侧的歌词徽标含义如下：

| 徽标 | 颜色 | 含义 |
|---|---|---|
| **歌词** | 绿 | 已写入**带时间轴**的 `.lrc`。可能是歌词源真实同步歌词，也可能是应用按音频时长**合成**的近似时间轴（见下方提示）。 |
| **歌词(纯)** | 绿 | 写入的是**纯文本**歌词（当前环境无法确定音频时长，无法合成时间轴）。部分音箱可能只能整段显示、无法逐行滚动。 |
| **歌词?** | 琥珀 | 匹配**可疑 / 不匹配**，应用**不会写入任何歌词文件**，需要你人工核对歌名或手动补充。 |
| **无歌词** | 灰 | 歌词库未检索到对应条目。 |

- 把鼠标停在徽标上可查看 **tooltip**：包含「匹配度 X%」「时长一致 / 时长未校验」「带时间轴 / 近似时间轴(按音频时长均分) / 纯文本(无时间轴)」等校验信息。
- **点击徽标即可直接打开对应的 `.lrc` 文件**，方便你肉眼核对歌词内容是否与歌曲对应。

## 4. GC200Pro 等音箱适配

这类云音箱 / 喇叭通常通过扫描**同名 `.lrc`** 来滚动显示歌词，且**需要带时间轴**（格式如 `[mm:ss.xx]`）：

- 若歌词源提供真实同步歌词（标准 LRC），直接写入，音箱可逐字滚动。
- 若歌词源**只有纯文本**（如本仓库当前主要依赖的 LRCLIB 对部分老歌仅提供纯文本，而网易云接口可能被风控无法取用），应用会**按音频真实时长把每行均匀铺开，合成标准的带时间轴 `.lrc`**。这样音箱依然可以滚动显示，内容则是正确的歌词——只是时间戳是近似的、不与演唱逐字对齐。
- 把输出目录整体交给音箱配套 App 导入即可（同名 `.lrc` 是这类设备的标准约定）。

## 5. 设置与歌单管理

- **输出目录**：歌曲与歌词的保存位置，可随时更改（更改后新下载的文件落到新目录）。
- **并发数**：同时下载的任务数量，默认适中，网络弱时可调小。
- **取消 / 清空已完成**：支持单条取消与批量清理已完成条目。
- **持久化**：歌单与设置基于 `electron-store` 自动保存，重启应用不丢失。

## 6. 注意事项

1. **版权合规**：请仅用于个人学习 / 欣赏，遵守相关地区法律法规与平台条款。
2. **Windows 未签名**：安装时 SmartScreen 会拦截，属正常，手动允许即可。
3. **macOS 未公证**：首次打开未签名 dmg 可能需在「隐私与安全性」中允许。
4. **歌词依赖外网**：
   - 主源为公开的 **LRCLIB**；网易云作为补充源，当前环境可能被风控（返回 `-462`），此时自动静默跳过，不影响主流程。
   - 老歌 / 冷门歌可能只有纯文本歌词 → 应用合成近似时间轴（见第 4 节）。
5. **歌词防错机制**：匹配以「曲名相似度」为主导并设下限（`>=0.5`），再加音频时长一致性校验。**任何候选曲名相似度不达标，应用都不会写入歌词文件**，从机制上杜绝把检索返回的「别的歌」的歌词张冠李戴写进去（例如不会出现《歌唱祖国》里是喜羊羊歌词的情况）。
6. **首次启动联网下载**：若系统未安装 `yt-dlp` / `ffmpeg`，应用会在首次使用时联网把它们下载到用户数据目录；之后离线可用（歌词仍需联网获取）。
7. **输出目录建议本地磁盘**：避免放在网络盘 / 同步盘，减少转码与写入异常。
8. **网络要求**：`yt-dlp` 访问 B 站需要正常网络；如处在受限网络，可能需要自行配置代理。
